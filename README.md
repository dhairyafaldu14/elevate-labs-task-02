# Task 2: Exploratory Data Analysis (EDA)

## AI & ML Internship – Elevate Labs

### Objective
To explore and understand a dataset using descriptive statistics and data visualizations. The goal is to identify patterns, trends, relationships, and anomalies in the data.

### Dataset
**Customer Shopping Trends Dataset**

- Total Records: 3,900
- Total Columns: 18
- Missing Values: 0
- Duplicate Records: 0

### Tools & Libraries Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

### Tasks Performed

1. Loaded and explored the dataset.
2. Checked dataset dimensions, column names, data types, missing values, and duplicate records.
3. Generated summary statistics for numerical and categorical features.
4. Created histograms to understand numerical feature distributions.
5. Used boxplots to examine potential outliers.
6. Created a correlation heatmap to study relationships between numerical features.
7. Used a pairplot to visualize relationships between numerical features.
8. Analyzed product category and seasonal purchase distributions.
9. Identified patterns and made feature-level inferences.

### Key Findings

- The dataset contains 3,900 records and 18 columns.
- No missing values or duplicate records were found.
- Boxplots did not indicate potential outliers in the selected numerical features using the 1.5×IQR rule.
- The selected numerical features showed very weak linear correlations.
- The pairplot did not reveal clear relationships between the selected numerical features.
- Spring recorded the highest number of purchases, while Summer recorded the lowest.
- Purchase counts were relatively evenly distributed across the four seasons.
